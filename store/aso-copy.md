## Full description (max 4000 chars both stores)

```
Stop retyping the same emails, replies, and snippets. Templateify Pro turns your most-used text into fill-in templates — tap, fill the blanks, copy, done. Works fully offline.

HOW IT WORKS

1. Create a template. Type your text. Highlight any word or phrase and turn it into:
   • A BLANK — a fill-in field (e.g., "Hi [Client Name]")
   • An OPTION — a pick-one dropdown (e.g., "Status: [On track / Needs review / Blocked]")
   • A PRIVATE FIELD — a hidden value (e.g., "[API key]") that masks on screen and copies on tap

2. Fill it in. Open the template, fill the form, and the final text appears in a live preview.

3. Copy or share. One tap to copy to clipboard, or use your device's native share sheet to send it to email, chat, or any app.

WORKS OFFLINE

Everything is stored locally on your device. No account, no cloud, no internet required. Your templates are private.

KEY FEATURES

• Fill Mode — a clean form for filling in templates. No more editing the template by accident.
• Edit Mode — for creators. Highlight any text to turn it into a blank, option, or private field.
• Nested folders — organize templates into folders and subfolders.
• Hashtags + search — find any template fast.
• Multi-format import — PDF, TXT, Markdown, DOCX, HTML, Python, Jupyter notebooks.
• Multi-format export — TXT, Markdown, HTML, PDF, Python, Jupyter, JSON, template files.
• Live preview — see exactly what you'll copy before you copy it.
• Remember last values — optionally save your fill-in values per template.
• Dark mode — easy on the eyes.
• PWA installable — add to home screen on any device.

FREE TIER

• Unlimited local templates
• Fill Mode + live preview
• TXT + Markdown export
• All import formats
• Nested folders + search
• Banner ad at the bottom (never full-screen ads)

PRO TIER — $4.99 one-time

• All export formats: PDF, HTML, Python, Jupyter
• Unlimited private fields (free is limited to 2 per template)
• Template lock — protect fixed text from accidental edits
• No ads
• Coming soon: starter pack library, mail-merge

USE CASES

• Customer support — templated replies with customer name, ticket number, status
• Sales — quotations with client, project, and rate fields
• Freelancers — invoices, contracts, scope-of-work snippets
• Social media — post templates with hashtag + emoji options
• Developers — code snippets, commit message templates, API request templates
• Meeting minutes — agenda, attendees, decisions, action items
• Daily standups — yesterday / today / blockers
• Personal — birthday messages, RSVP replies, recipe templates

PRIVATE FIELDS

Private fields hide sensitive data (API keys, passwords, internal pricing codes) behind a label. They're masked on screen and copy-to-tap. Perfect for screen-sharing or demo situations where you need to use a value without showing it.

NOTE: Private fields are a UX feature, not a security feature. Values are stored locally in plaintext. Don't store high-secrets in them — use a password manager for those.

OFFLINE-FIRST

No cloud. No sync. No account. Your data lives on your device. To move data between devices, use the JSON backup/restore feature (export from one device, import on another).

ROADMAP

• Phase 3: Cloud sync (optional SaaS subscription) — encrypted backup, cross-device sync, share-a-template links
• Phase 4: Mail-merge (fill one template against CSV rows → export many outputs), AI template extractor (paste a document, AI detects blanks), team folders, community marketplace

SUPPORT

Privacy: https://templateify.com/privacy
Terms: https://templateify.com/terms
```
